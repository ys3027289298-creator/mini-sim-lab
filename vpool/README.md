# vpool

可扩容顶点缓冲池，代际句柄 + 逻辑槽→物理槽索引映射。

扩容（压缩搬迁到两倍大的新 arena）时保证三条不变量：

1. 槽位顶点数据整体搬迁（`Tri` 逐字节复制，不重新初始化）；
2. 代际位只复制、不重置，过期句柄继续失效，存活句柄继续有效；
3. 索引映射表 `map[logical] -> physical` 在同一趟里重建。

过期/畸形句柄的 `submit` 直接返回 -1 且不写任何像素；释放的物理槽会被
填充标记，不会画到脏数据。

`make test` 跑自检（含连续三次扩容稳定性、扩容/未扩容两条路径逐像素
比对）；`make asan` 用 ASan+UBSan 再跑一遍。
