# pool

`make test` 跑自检。

定容对象池 + 代际句柄，并支持句柄持久化。

## 句柄

- `Handle` 固定 8 字节（u32 `index` + u32 `gen`），编译期 `_Static_assert` 锁定体积。
- 槽位释放时 `gen` 递增，旧句柄的代际对不上即判失效，不会命中复用槽。

## 存档 / 读回

- `pool_save(p, refs, nref, path)`：把池状态和外部持有的句柄表写成小端二进制；
  所有句柄必须当前有效，含失效句柄直接拒绝。先写 `path.tmp` 再 `rename`，原子落盘。
- `pool_load(p, refs, cap_refs, &nref, path)`：整文件校验通过后才提交，
  任何一步失败目标池原样保留。校验内容：
  magic/version/容量、每槽状态（存活槽代际非 0）、计数一致性、文件无多余字节；
  每个句柄必须命中存活槽且代际精确相等——代际冲突整体拒绝，绝不解析到复用对象。
- 磁盘布局全部定宽：句柄在盘上也是 8 字节/个，与内存表示同构。
- 读回后逐槽状态与存档前一致，句柄查询值逐对象一致；读回后的释放/复用继续沿用代际机制。
