## 句柄与碎片整理

- 句柄是 `{index, gen}`，`index` 指向稳定的句柄表项，`gen` 每次分配唯一，
  所以过期句柄查询失败而不是读到新对象。
- `pool_compact` 把存活对象按槽位顺序压到低地址，搬移 7 个对象后原本
  8 个散落的空槽合并为一段连续 8 槽。
- 搬移只改句柄表里的槽位指针，调用方句柄不变；迁移前先把表项指向新槽，
  再释放旧槽，因此整理期间不存在悬垂窗口。
- `compact_moves` 累计迁移对象数；`compact_violations` 记录整理途中发现的
  结构不变量破坏（实测为 0）。
- 整理前后可用槽位总数不变，变化的是最大连续空槽长度；再次整理无对象可搬。
