# mini-sim-lab

游戏运行时基础设施，C 实现，每目录独立构建可自测。

| 目录 | 内容 |
|---|---|
| `fixedstep/` | 固定步长累积器、插值 alpha、追帧上限 |
| `pool/` | 定容对象池、代际句柄、悬垂检测 |
| `rng/` | 随机流、快照与分叉、无偏范围 |
| `det/` | 共享确定性上下文与逐位可复现证据 |

## 构建与自检

```sh
make            # 构建全部模块与证据驱动
make test       # 各模块原有自检（输出与改造前逐字节一致）
make det        # 确定性证据：两次运行、线程无关、共享开关、非法参数定位
```

确定性证据的完整说明、逐模块哈希与可复制复现命令见 [`det/README.md`](det/README.md)。
