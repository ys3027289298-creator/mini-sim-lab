# merkle

存档分块 Merkle 校验。payload 按定长块切分成叶子，逐层两两合并到根；
整棵层级树与定长头部放在存档尾部的校验区，读档时可以全量校验，也可以
只对调用方给出的脏块走兄弟路径做 O(log n) 校验。

`make test` 跑自检（SHA-256 已知向量、零误报矩阵、逐块篡改定位、兄弟路径、
校验区伪造、磁盘往返与只读保证）。

## 文件格式

```
+-----------------------------+
| payload（原始字节，原样不动） |
+-----------------------------+
| header        72 字节        |
| tree nodes    n*32 字节       |  层级顺序：叶子层 -> ... -> 根
| header digest 32 字节        |  SHA256(0x03 || header)
| trailer size   8 字节 (u64)  |
| tail magic     8 字节        |
+-----------------------------+
```

- 哈希：自实现 SHA-256，无外部依赖
- 域分隔：叶子 `SHA256(0x00||block)`、合并 `SHA256(0x01||L||R)`、
  填充叶 `SHA256(0x02)`、头部摘要 `SHA256(0x03||header)`，节点类型不可混淆
- 叶子数补齐到 2 的幂，填充叶为固定常量，所有路径深度统一
- 校验区每个字节都受哈希保护：树节点在根的承诺之下，头部由 header digest 认证
  （多字段协同伪造也无法通过）

## API 与错误码

| 函数 | 作用 |
|---|---|
| `mk_build` | payload + 块大小 -> 带校验区的新缓冲（不修改输入） |
| `mk_open` | 解析并做结构/版本/摘要校验，返回 `MkCtx` |
| `mk_verify_full` | O(n) 全量校验，返回所有坏块下标；校验区本身损坏置 `tree_tampered` |
| `mk_verify_block` | 单块 O(log n) 证明校验，输出路径上每个兄弟节点及左右位置 |
| `mk_verify_changed` | 只校验脏块列表，哈希过的块数 == 列表长度（自检计数验证） |
| `mk_snapshot_leaves` | 拷贝根承诺下的叶子摘要，供两版存档 diff |

错误码：`SHORT / MAGIC / VERSION / BLOCK_SIZE / EMPTY / LENGTH / TREE /
DIGEST / ROOT / TAMPER / INDEX / NOMEM / IO`。零块长与空 payload 在 build
和 open 两侧都拒绝；版本不符返回 `VERSION`。

## 保证

- **零误报**：8 种 payload 长度 × 4 种块大小矩阵 + 4 万次随机 fuzz，干净存档
  全部通过；SHA-256 抗碰撞下篡改检出概率为 1（碰撞概率 2^-128）
- **精确定位**：任意 payload 字节被改，全量校验恰好返回其所属块，且只返回该块；
  其余块单独证明校验仍然通过
- **兄弟路径**：`mk_verify_block` 输出每层兄弟哈希与 `sibling_on_left`，
  自检证明输出的就是树中实际存储的兄弟节点
- **只读**：所有校验入口接收 `const` 缓冲，自检用逐字节比对证明校验前后
  存档零变化；写入只发生在 `mk_build` 新分配的缓冲里
