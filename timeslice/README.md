# timeslice

跨帧时间切片：剔除 / 阴影 / 后处理按帧预算拆到多帧，可中断续跑。

`make test` 跑自检。

画面被切成 `TILE x TILE` 的工作单元，每个阶段（cull → shadow → post）
把全部 tile 扫一遍，单元之间是阶段屏障，所以阴影阶段读到的永远是
完整的可见性缓冲。每帧给出一个 cost 预算；调度器只在“下一个单元会超预算”
时让出，从不把一个单元拆开，因此任意中断点都是自洽状态。续跑点是
`(stage, index)` 加三个中间缓冲，全在 `Pipeline` 里，直接拷贝即可分叉。

自检覆盖：

- 单帧全量跑出的参考画面 vs 多种预算下的切片画面，`out`/`lit`/`vis`
  三块缓冲逐字节一致；
- 切片数、总 cost、平均/最大帧时间、让出帧数、阶段跨越数都打印出来；
- 中途中断后快照，两条续跑路径结果与参考一致，且工作总量不重算；
- 预算小于单个单元、甚至为 0 时仍每帧推进一个单元，不会死锁。
